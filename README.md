# MqttCoroutines

> ⚠️ **DEPRECATED / ARCHIVED**
> This project is no longer maintained. Please use **[stem-mqtt](https://github.com/sorinirimies/stem-mqtt)** instead.

[stem-mqtt](https://github.com/sorinirimies/stem-mqtt) is the complete successor to MqttCoroutines. Unlike this library, which only wrapped the Java Eclipse Paho client, it:

- covers more languages and platforms,
- provides both an MQTT **client** and a **broker**,
- is not tied to the Java Paho client.

Head over to **https://github.com/sorinirimies/stem-mqtt** for installation and usage.
